İşaretlemezsen token sekme kapanınca silinir. Ortak kullanılan cihazlarda işaretleme.

Token nasıl oluşturulur?
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → sadece bu reposu.
  3. Permissions → Repository permissions → Contents: Read and write. Başka izin gerekmez.
  4. Oluşan token'ı kopyalayıp buraya yapıştır.
